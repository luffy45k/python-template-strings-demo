# Changelog

All notable changes to this project are documented here.

## 1.2.0 — 2026-10-01

### Added

- Mrx interactive chatbot with bounded in-memory conversation history.
- Dependency-free, escaped SVG bar, line, and pie charts.
- Chat-driven chart creation and a replay-safe chart agent tool.
- Local responsive web chat with JSON chat, health, and address endpoints.
- Automatic free-port selection and local DHCP/interface change monitoring.
- Web request limits, bounded sessions, and browser security headers.

## 1.1.0 — 2026-10-01

### Added

- Guarded autonomous-agent runtime with bounded memory and audit trails.
- Allowlisted HTTPS client with SSRF, redirect, size, and content-type controls.
- Ephemeral Playwright browser automation with action and navigation policies.
- Dedicated non-root browser sandbox image.
- Mrx runtime identity, Kali mini image, and native Termux launcher.
- Replay-safe runtime recovery with recovery metrics.
- Approval-gated transactional code repair with automatic rollback.
- Offline container health checks and restart-ready images.
- Python 3.10–3.14 CI matrix and automated dependency updates.

### Changed

- Upgraded development tooling to pytest 9.1, pytest-cov 7.1, Ruff 0.16.9,
  Hatchling 1.32, and Playwright 1.63 release lines.
- Raised minimum Python from 3.9 to 3.10 to follow current upstream tooling.
- Added formatting and wheel-build checks to CI.

## 1.0.0 — 2026-10-01

- Initial compatible PEP 750 data model, renderers, SQL parameterization,
  self-healing retries, chaos testing, CLI, tests, and packaging.
